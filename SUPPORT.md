# Support

For problems with Acadia Syntax, email
[flaviocorpa@gmail.com](mailto:flaviocorpa@gmail.com).

When reporting a highlighting issue, please include:

- a minimal Acadia `*.db` example;
- the expected highlighting;
- the VS Code theme and version in use; and
- a screenshot when the difference is visual.

For questions about the language itself, consult the
[Acadia documentation](https://acadia.engineering/documentation).
