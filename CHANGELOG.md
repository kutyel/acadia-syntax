# Changelog

All notable changes to Acadia Syntax are documented in this file.

## 0.1.2 - 2026-07-23

- Add the Acadia logo as the Visual Studio Marketplace extension icon.
- Link the extension metadata to the public Acadia Syntax GitHub repository and
  issue tracker.

## 0.1.1 - 2026-07-22

- Align module, type, constructor, record-field, and top-level value scopes with
  the Elm VS Code extension.
- Improve highlighting for qualified imports, type aliases, type annotations,
  and record types.
- Add TypeScript and pnpm-based grammar validation.

## 0.1.0 - 2026-07-22

- Add initial syntax highlighting for Acadia `*.db` files.
- Recognize Elm-style syntax and Acadia-specific `database`, `endpoint`, and
  transactional `:=` constructs.
- Add comments, strings, numeric literals, documented operators, and editor
  configuration.
